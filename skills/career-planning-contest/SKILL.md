# 职规赛报名 + 生涯闯关

这个 skill 记录的是**已经跑通过两遍**（本人一次、帮同学一次）的真实操作路径。平台是学信网的职规赛系统 `https://zgs.chsi.com.cn`，页面是 React + antd 的自定义组件，很多地方不能靠 snapshot 点，得按类名/文本 dispatch 事件。

## 0. 先守住三条（比任何步骤都重要）

1. **登录、验证码、密码永远由本人来。** 你能做的是打开页面、等她登录完再接手。
2. **「确认参赛」是不可逆提交。** 点之前必须把当前表单状态复述或截图给她/本人确认，得到明确「点吧」再点。
3. **替别人做时：** 只用对方授权的内容；代写的访谈报告、实习证明之类材料，交付时写明「按你提供的真实经历写成，可替换」，不要编造获奖、实习单位、成绩。

## 1. 开工前必须向用户问齐的信息（缺一项就会卡住）

**这一节是给 agent 的开工清单。** 一次问完，别边做边问。

### 1.1 账号（唯一不能代劳的部分）

| 要问的 | 为什么 | 谁来做 |
|---|---|---|
| 用哪个学信网账号（本人 / 帮别人做） | 平台按账号区分报名记录与闯关进度 | 用户 |
| 能不能自己登录（密码、短信验证码） | agent 不碰密码与验证码 | 用户登录，agent 接手 |

登录成功的判据：页面右上角出现「你好，XXX」，且能看到学校与专业。

### 1.2 报名三项（决定后面所有材料的口径）

| 要问的 | 说明 |
|---|---|
| 赛道 | 本科生一般「成长赛道」，研究生/在职「就业赛道」 |
| 组别 | 本科「高教组」，高职「职教组」 |
| 目标职业 | 越具体越好（要能落到平台清单的二级项，例如「工程技术类 / 石油与天然气工程技术人员」）；不确定就先看「职业全览」再定 |
| 目标行业 | 平台只有 10 项：农林 / 能源动力 / 材料化工 / 装备制造 / 信息通讯与互联网 / 交通运输与邮政快递 / 建筑地产 / 金融 / 商贸服务与生活消费 / 科技服务 |

### 1.3 指导教师

姓名、手机号、所在院校。同校同队时通常与上一次相同，可直接复用并让用户确认一次。

### 1.4 两份材料需要的素材

| 要问的 | 用来写什么 |
|---|---|
| 想做的方向（一句话，越具体越好） | 决定报告标题、目标职业、PPT 与闯关的统一口径 |
| 真实经历 3 条以上（课程 / 实习 / 科研 / 竞赛 / 社团） | 报告的「已有成果」、闯关的成就故事（STAR） |
| 能力自评：强项 2–3 个、短板 2–3 个（可给 0–100 分） | 雷达图与条形图的分数（报告 / PPT / 闯关三处必须一致） |
| 可用的图表数据或公开资料（招聘简章、培养方案、就业质量报告） | 报告图表、第 5 关的「招聘简章 + 阅读体会」 |
| 想强调的价值观（求稳 / 求成长 / 求待遇…） | 「自我认知」与「评估调整」的语气 |

### 1.5 要做「生涯闯关」时额外要问

| 要问的 | 用在哪一关 |
|---|---|
| 生涯榜样 2–3 位（姓名 / 身份 / 单位） | 第 1 关 生涯愿景 |
| 本专业核心课程 5–8 门 | 第 2 关 专业探索 |
| 想访谈的对象与岗位（可虚拟职务层级，但不编单位与荣誉） | 第 3 关 职业瞭望 |
| 兴趣倾向（喜欢动手 / 数据 / 与人打交道 / 文书） | 第 4 关 兴趣揭秘（Holland 词条与排序） |
| 具体岗位名（会写成「职业方向探索记录」，第 6 关会引用） | 第 3、6 关 |
| 一段能讲成 STAR 的真实经历（情境/任务/行动/结果） | 第 6 关 成就故事 |
| 三项技能提升计划（学什么、怎么练、什么时候） | 第 7 关 技能提升 |

### 1.6 不要问的

- 密码、验证码、身份证号、学号——不需要，也别记录。
- 让他自己决定「交不交、点不点提交」——agent 只准备，不代替本人点不可逆按钮。

目标职业不确定时，先点报名页的「职业全览」看完整清单再定；「职业全览」是只读展板，**选职业要走职业输入框的级联选择**，两处不是一回事。

## 2. 报名表四步（页面 `/center/signup/filed`）

1. **赛道 / 组别**：默认已勾好（成长赛道 = radio value 2，高教组 = value 1）。先核对，别想当然。
2. **目标职业**：点进职业输入框（antd cascader，`#job_id`），输入关键词 → 列表里点中二级项（文本形如「工程技术类 / 石油与天然气工程技术人员」）。选完看 `#job_id` 旁的 breadcrumb 显示对不对。
3. **目标行业**：antd Select `#industry_ids`，全部只有 10 项（农林 / 能源动力 / 材料化工 / 装备制造 / 信息通讯与互联网 / 交通运输与邮政快递 / 建筑地产 / 金融 / 商贸服务与生活消费 / 科技服务）。
4. **指导教师**：点「添加指导教师」→ 弹窗里 `#name`、`#mobile`、`#school_code`（antd Select，输入「XX 大学」选 XXXXX 这类院校代码）→ 保存，页面出现「指导教师 XX 手机号码：… 所在院校：…」。

antd 组件的通用点法：先把点击打到 `.ant-select-selector` / 输入框上并 `dispatchEvent(new MouseEvent('mousedown', {bubbles:true}))` 把下拉打开，再点 `.ant-select-item-option`（同样 mousedown → mouseup → click）。

## 3. 两份材料怎么做

格式硬约束（通知里的原话）：**生涯发展报告 PDF，正文 ≤1500 字、图表 ≤5 张**；**生涯发展展示 PPT ≤50MB**。学生手册里的细则可能更严（例如 PDF <10M），按页面提示走。

制作与自检的具体做法见 `references/materials.md`；一句话版本：用 Python 生成 HTML（手写 CSS + SVG 图）→ 用 CDP 的 `Page.printToPDF` 打 PDF；PPT 用 python-pptx 写脚本生成，再用 PowerPoint COM 导 PNG 逐页看版式。

内容口径要一致：报告、PPT、闯关作答讲的是**同一个职业、同一套能力自评**（雷达/条形的分数在三处必须一致），否则评委一眼看出拼凑。

## 4. 上传与提交

- 报名页有两个 `input[type=file]`：`accept=".pdf"` 与 `accept=".ppt,.pptx"`。
- **上传 PPT 必须显式指定 mime** `application/vnd.openxmlformats-officedocument.presentationml.presentation`，否则 OSS 直接 403。
- 勾选「已阅读诚信声明」的 `input.ant-checkbox-input`，然后点「确认参赛」→ 弹窗确认 → 成功 toast「报名成功！」，页面变成「成长赛道 · 待审核 · 高教组」。
- 提交后仍可在报名时间段内修改；提交前一定要让本人复核。

## 5. 生涯闯关总览

入口：`https://zgs.chsi.com.cn/mine/info`（等同于 `/mine/recruit`）。**`/center/checkpoint` 的「去闯关」会 `window.open` 新窗口，那个窗口你切不过去**——直接 `newTab` 打开 `/mine/info` 更省事。

- 列表是 8 张徽章卡（`div.medal_list___1jWeL`），按钮 `span.recruit_text___2hbQF` 文本「去闯关」。
- 关卡 URL 与 barrier id 对不上号，记住这张表：`/checkpoint/first`=1 生涯愿景、`second`=2 专业探索、`third`=3 职业瞭望、`fifth`=5 兴趣揭秘（页面显示「04」）、`sixth`=6 目标锚定、`seventh`=7 能力盘点、`eighth`=8 技能提升、`ninth`=9 生涯启航。**没有 id 4。**
- 每关三段：**新知**（`/newknowledge`）→ **笃行**（`/practiceearnestly/entrance`，可能拆成多张图 = 多个子任务）→ **领悟**（`/comprehend`）。
- 完成判定看徽章图的 background-image 是否变成 `medal_light_*`（命名有 `medal_light_1` / `medal_light_new_2` 等变体，别用固定正则），列表文字「去闯关」会滞后，要刷新。
- 每关的入口、字段 id、字数区间、提交点：见 `references/levels.md`。
- 常见故障与对策：见 `references/pitfalls.md`。

## 6. 验收清单（做完必须逐条过）

- [ ] `/center/signup` 显示「成长赛道 · 待审核 · 高教组」，两份材料都在，指导教师信息正确。
- [ ] 报告 PDF：页数合理（2–3 页）、正文汉字数 ≤1500（`re.findall(r'[\u4e00-\u9fa5]', text)` 数一遍）、图 ≤5 张。
- [ ] PPT：≤50MB、16:9、每页无文字溢出（导 PNG 看过）。
- [ ] 闯关：8 张徽章 `backgroundImage` 全是 `medal_light_*`。
- [ ] 交付说明里写清：哪些内容是本人提供、哪些是我代写、哪些需要她自己补（例如要交到学校后台的报名情况）。
- [ ] 提醒本人：报名完成后按学院要求把报名情况录进学校后台（这一步平台不会替她做）。

## 7. 三条判据，避免自己骗自己

1. **「提交成功」toast 出来了 ≠ 这一关完成。** 笃行里每个子表单提交后，往往还要在笃行页再点一次「提交」；最终以徽章点亮为准。
2. **领悟报「请先完成 新知 和 笃行 环节」= 笃行还有子任务没做**（多张图的那关尤其容易漏）。
3. **页面回到引导语没有报错，也可能只是导航成功而不是保存成功。** 保存类操作后用 `execute` 复查字段值或看接口返回。
